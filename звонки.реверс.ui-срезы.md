### 2.4 Статусы и формат времени (точные строки из S1/S3/S4)
⚠ Стрелка = **направление звонка**, а не статус: `arrow_down_left_12` — входящий,
`arrow_up_right_12` — исходящий; встречается у ЛЮБОГО статуса (проверено по S3: «Отменённый · 12:37»
с down_left и «Отменённый · 12:07» с up_right). У «Групповой» стрелки нет.
| Статус | Формат подписи | Примеры направлений |
|---|---|---|
| Завершённый | «Завершённый · 14:28» (сегодня = HH:MM) | обе стрелки |
| Завершённый | «Завершённый · вчера» / «Завершённый · 24 августа» | обе стрелки |
| Пропущенный | «Пропущенный · вчера» / «Пропущенный · 23 августа» / «Пропущенный · 3 сентября 2025» | только down_left (по определению входящий) |
| Отменённый | «Отменённый · вчера» / «Отменённый · 24 августа» / «Отменённый · 23 августа» | обе стрелки (входящий, который не взяли/сбросили до ответа, тоже «Отменённый») |
| Групповой | «Групповой · 8:14» (без стрелки, время начала) | — |

Длительность в строке истории НЕ отображается (длительность есть только в сервисных сообщениях
чата — §7.2).

### 2.5 Кластеризация последовательных звонков
Счётчик в заголовке: «Имя Фамилия (N)» — N = число звонков в кластере. Набор S1:
(2)×3, (3)×2, (4)×2, (5)×1 + одиночные. S3: (4), (2)×4, (3). S4: **(10)×2, (9)×1** — счётчик
пропущенных кластеров. Внутри кластера в списке одна строка; статус-строка — ПОСЛЕДНЕГО звонка
(в S3 «Сергей Ширабоков (2) || Отменённый · 12:06» при соседних 12:07).
«Действия» и redial-кнопки у кластера те же, что у одиночной строки; aria-текст содержит имя
БЕЗ счётчика у части строк и со счётчиком у других (S4: «Аудиозвонок Сергей Ширабоков (10)»).

### 2.6 Список статусов по S1 (главная, 25 строк)
Групповой×2 («Групповой · 8:14», «Групповой · 8:02»), затем: Завершённый·вчера×9,
Пропущенный·вчера×4, Отменённый·вчера×2, Завершённый·24 августа×3, Пропущенный·24 августа×2,

   «Действия», «Ещё»-содержимое) не сохранён — содержимое меню добирать по API плана §2.1.

4. `calls.getHistory` параметры (filter/pagination_marker) — из плана §2.1, в этих снапшотах
   не повторяются (только метод-список подтверждён).
5. Странные артефакты: `calls_call_patricipants` (опечатка VK в i18n-ключе), дубли метода
   `getCallPreview` в двух namespace (`calls` и `messages`).

   верстать IncomingCallScreen/IncomingCallBanner без дополнительных срезов.
