## §5. Честные ограничения

1. **SPA-снапшоты**: посты серио-рендеред частично (6/4/7/0/5 карточек); JSON-ответов ленты нет (apiPrefetchCache пуст на всех 5 страницах) → все ключи ответов (items/profiles/groups/next_from/reactions_counts) известны только из бандлов и ядра, не из живого дампа.
2. **Async-чанки не сохранены**: call-sites `newsfeed.getLikesFeed`/`getByType`/`getFeed`-запросов (параметры count/filters/source_ids) — только регистрации классов/кэша; параметры восстановить нельзя.
3. **Форма фильтров поиска пуста** (страница сохранена до ввода) — поля автор/группа/дата не сняты; сериализация `search_filters_form` известна, состав полей нет.
4. **Тексты web-меню «Действия»** не сохранились (lang-чанки без news_*-ключей; найдены global_report_spam/global_report_sent); состав меню реконструирован по JS-хендлерам — порядок/точные формулировки web не воспроизводимы.
5. **«Колёсико фильтров ленты»** в DOM отсутствует: правое меню — навигация разделов + «Редактировать»; настройки показа (компактный вид и пр.) в снапшоте не найдены (прежний док лента.md трактовал это как «правое меню фильтров» — скорректировано §1.0.2).
