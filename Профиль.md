## 1. Архитектура загрузки профиля (КЛЮЧЕВОЕ)

### 1.1. Профиль НЕ использует `execute.VKScript`

Профиль грузится через **12 индивидуальных prefetch API-вызовов**, встроенных в HTML как `window.cur.apiPrefetchCache` (211 KB JSON, HTML-entity-кодированный). Все 5 вкладок шарят ОДИНАКОВЫЕ 12 prefetch-вызовов; per-tab контент (аудио-список, стена, фото-сетка, видео-каталог, клипы) фетчится on-demand после загрузки динамиически-подгружаемыми SPA-чанками.

### 1.2. 12 prefetch-вызовов (в порядке)

| # | Метод | Параметры | Назначение |
|---|---|---|---|
| 1 | `utils.resolveScreenName` | `screen_name:"pluton_tut"` | URL slug → `{object_id:171093180, type:"user"}` |
| 2 | `users.get` | `user_ids`, `fields:<100+ полей>` | Полный объект профиля (см. §4) |
| 3 | `users.getContentTabs` | `user_id`, `scrollable_tabs:1` | Каталог 7 вкладок (см. §3.1) |
| 4 | `users.getWallTabs` | `user_id` | Sub-вкладки стены (all/owner/archived + counts) |
| 5 | `stories.get` | `owner_id` | Сторис пользователя (0 у этого юзера) |
| 6 | `account.getCounters` | — | Бейджи текущего юзера (messages, notifications, channels) |
| 7 | `account.getInfo` | `fields` | Настройки текущего юзера |
| 8 | `account.getSilentModeStatus` | — | Беззвучный режим |
| 9 | `account.getHelpHints` | — | 393 UI-подсказки (tooltip texts) |
| 10 | `friends.getRecommendations` | `friend_id`, `ref:"profile"`, `count:20`, `need_description:1`, `fields` | «Возможно, вы знакомы» |
| 11 | `articles.getOwnerPublished` | `owner_id`, `count:30` | Опубликованные статьи |
| 12 | `fortuneWheel.getReceivedThrows` | `user_id` | Промо |

### 1.3. apiPrefetchCache mechanism

`loadPrefetchCache(method, version, request)` (бандл `b-483d721ddc25ecc0`):
- Читает `window.cur.apiPrefetchCache` (HTML-entity-decode через `decodeHTMLEntitiesDeep`)
- Матчит по `{method, version, request}` deep equality через `Array.findIndex`
- **Splice'ит entry при чтении** (one-shot cache — одноразовый)
- Miss'и трекаются через `api_prefetch_cache_miss` statlogs event

## 6. Auth & Token Flow

### 6.1. Залогиненный юзер (есть `remixsid` cookie)

1. `fetch("https://login.vk.com/?act=web_token&<params>", {credentials:"include"})` → `{data:{logout_hash, token, user_id, ttl}}`
2. Хранится в localStorage как `{access_token, expires:ttl, user_id, logout_hash}`
3. Все API-вызовы: body содержит `access_token`, `v=5.282`, `app_id`
4. При истечении: `onTokenExpired` → re-fetch через `q(e, true).then(({access_token}) => access_token)`

### 6.2. Анонимный юзер (нет `remixsid`, публичные профили)

1. `fetch("https://api.vk.com/get_anonym_token?...")` → `{access_token, expires}`
2. Переименование перед отправкой: `M.anonymous_token = M.access_token; delete M.access_token`
3. Flag `loginvk_api_use_anonymous_token` включается когда `window.vk?.id <= 0`
4. Flag `isApiOauthAnonymEnabled` — кэширование anonymous token

### 6.3. API URL & version

- URL: `https://api.vk.com/method/<method>?<params>` (или `api.vk.ru` по flag `frontend.change_api_domain`)
- Version: **`v=5.282`** (из apiPrefetchCache metadata)
- Cookies: `credentials:"include"` — `remixsid` (web session), `remixst`/`remixstpin` (staging)
- Body fields: `access_token` (или `token` если `useAPIGateWay:true`), `v`, `app_id`, `client_secret` (только неавторизованным)

### 6.4. Кэш API (client-side)

`(setApiConfig)({cache:{maxSize:10485760, methods:{...}}})` — 10 MB LRU. Кэшируемые методы:
`friends.get/getLists/getCounters/getOnline/getRecommendations`, `catalog.getGroups/getAudio/getSearchAll`, `photos.getAlbums/photoFeedGet`, `docs.get/getTags/getTypes`, `account.getCounters/getInfo/getProfileInfo`, `notifications.getRedesign/getUnreadCounters`, `internal.getWebLeftMenu`, `account.getProfileMenuData/getProfileNavigationInfo`, `utils.resolveScreenName` (special: `maxVariations:100` — до 100 разных screen_name).
