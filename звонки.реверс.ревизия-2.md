## §1. Чат звонка (REV-DEEP-1) — внедрено в CallChatScreen

1. **История — messages.getHistory** (IM-SPA `83836.005a7c28.js` @1769954):
   `{peer_id, start_cmid, count, offset, extended:1, fwd_extended:1, [nested_limit:2]}`, `{retries:5}`.
   Направления web: назад (старее) → `offset=-1` С start_cmid; вперёд → `offset=1-p`;
   открытие чата → `offset=-floor(0.8·p)` с корректировкой по unreadCount
   (`u.inReadBy===i&&(h=Math.max(-u.unreadCount,h))` — семантика неоднозначна, нами не
   воспроизводится). Ответ: `items[{conversation_message_id, date, text, from_id, action?}]`.
2. **Отправка — messages.send**: builder «UserHitSend» (83836 @1541400) для текста шлёт
   `{peer_id, random_id, message}`; обёртка звонкового бридга — passthrough
   (`webCallsBridge @968528 ue=(e={})=>xP("messages.send")(e)`); живой пример random_id:
   `Math.round(2e9*Math.random())` (252761de @13996).
3. **Звонок → чат**: peer_id приходит ГОТОВЫМ из `calls.getConversationByCall({call_id,[hall_id]})`
   → `conversation.peer.id` (bridge @196400 `setRoomChatId`); `unread_count`/
   `last_conversation_message_id` — там же (SET_UNREAD_COUNT). Арифметика `+2e9` — ТОЛЬКО
   внутренняя IM-арифметика chat_id (common.662bde55 @1345069), для звонкового чата НЕ нужна.
   Реестр чатов: `messages.getConversationsById({peer_ids, extended:1, fields:"name,photo_100,
   photo_200,can_upload_video,custom_names_for_calls"})` (bridge @960662).
4. **Сервисные сообщения звонка** (switch IM-SPA 83836 @1275300), action.type:
   `chat_group_call_started`, `chat_invite_user_by_call`, `chat_invite_user_by_call_join_link`,
   `cannot_call_privacy_settings`, `chat_kick_user_call_block`, `call_transcription_failed`;
   langkey-паттерн `me_service_${action.type}` (+`_community`). Русские ЗНАЧЕНИЯ ключей в
   снапшотах не сохранились — подписи наши (KDoc CallChatScreen).
5. **Не найдено**: `messages.getHistory` в звонковых бандлах (web-чат звонка ходит через IM-стор
   FastChat/reforgedME — мы делаем прямой вызов, честный эквивалент); конверсия строкового
   conversation_id→peer_id (приходит готовым); cap random_id (`mf`).
