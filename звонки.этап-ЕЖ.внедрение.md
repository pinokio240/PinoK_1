## 2. Честные отклонения (no-stub)
- «Принять с видео» не рендерится (камера-передача — фаза 2, видеофлаг до offer неизвестен).
- Отдельной busy-кнопки в web-входящем нет (§8.1) — «Занят» реализован вариантом отклонения.
- BT-форсирование маршрута отсутствует (нет SCO-пути в WebRtcEngine) — контрол не рендерится.
- Пагинация участников `get-participant-list-chunk` через сигналинг — только если транспорт
  позволит; базово offset `calls.getParticipants`.
- Ж6–Ж11 (запись/ASR/зал ожидания/залы/watch together/трансляция/vmoji/фон/субтитры) —
  следующая волна (wire в Ж-0 готов).

## 4. Чек-лист пользовательской проверки (штамп calls-2026.09.06-2)
1. Входящий: полноэкранный (аватар/имя), Принять → звонок как раньше; Отклонить → у звонящего
   «отменён»; «Занят» → звонящий видит занятость; Свернуть → баннер поверх других разделов,
   тап — разворот; звонящий отменил → баннер исчезает («Звонок отменён»).
2. В звонке: кнопка участников — список с пагинацией; реакции — плашки уходят; рука — тоггл,
   синхронизируется сервером; чат — открывается чат звонка; настройки — шумодав/качество
   переключаются (сверить эффект звука); виджет — mute/разворот/завершение.
3. Регресс: обычные звонки (вкл. join по ссылке и видео из волны-4), история/записи/расшифровки.
