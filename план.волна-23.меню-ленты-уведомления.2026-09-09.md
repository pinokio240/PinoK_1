## Рекогносцировка (сделана оркестратором)

1. **Правое меню ленты** — `ui/components/FeedRightPanel.kt` (19-A, 779 строк):
   секции «Друзья онлайн» (friendsGetOnline), «Возможные друзья»
   (friendsGetSuggestions), «Рекомендуемые сообщества» (groupsGetCatalog),
   «Мои закладки» (faveGet). ЭТО НЕ ТО, ЧТО В VK WEB.
2. **VK web rightmenu** (лента.снапшоты.парсинг.полный.md §1.0.2,
   `data-testid="rightmenu"` aria «Список ленты») — НАВИГАЦИЯ РАЗДЕЛОВ ленты:
   `feed_right_menu_news` Лента (`/feed`) · `sources_photos` Фотографии ·
   `sources_friends` Друзья · `global_search` Поиск · `wall_likes` Реакции ·
   `sources_action_edit` «Редактировать» (менеджер лент/скрытых).
3. **Разделы ленты в PinoK УЖЕ работают** — FeedScreen `FeedFilter`
   (ALL/RECOMMENDED/LIKES/PHOTOS/FRIENDS/SEARCH; FRIENDS = лента постов друзей
   newsfeed.get(source_ids) IMP-FEED-1; LIKES = Реакции с 5 подтабами; SEARCH =
   newsfeed.search; PHOTOS = фильтр фото поверх ALL) + FeedFilterBar-dropdown.
   Меню-шторка должна ПЕРЕКЛЮЧАТЬ эти разделы (как VK web).
4. **«Редактировать»** — эквивалент готов: `Screen.FeedHidden` →
   FeedHiddenSourcesScreen («Скрытые источники», newsfeed.getBanned+unban,
   IMP-FEED-2); в FeedScreen колбэка нет — добавить.
5. **Фильтр уведомлений** (Fix #354): NotificationsScreen-фильтры матчят
   action-типы (like*/comment*/mention*/copy/follow/friend*), но
   `parseRedesignNotificationItem` (Fix #254) вычисляет type из
   **action.entity.type = ТИП ОБЪЕКТА** (post→new_posts, photo→photo…) —
   у web-токенов «Реакции/Репосты/Подписки/Упоминания» матчят 0 items →
   «фильтр почти не работает». Машинно-читаемая категория ЕСТЬ в ответе:
   `dots_menu[0] = {type:"open_setting", name:"new_posts"}` (доказано
   VK_IMPORT_API.MD ЧАСТЬ 34, лог 211KB) + действие глаголом в `item.text`
   («оценил/прокомментировал/поделился/подписался/…»).

## Решения

- **Fix #353 #FEED-MENU-VKWEB**: FeedRightPanel = навигация разделов (5 пунктов
  VK web + «Редактировать» → Screen.FeedHidden). Чекмарк на активном разделе.
  Старые секции (закладки/друзья онлайн/возможные друзья/сообщества) — УДАЛЕНЫ
  по прямому требованию юзера (VK web их в меню ленты не имеет). Блок «возможных
  друзей» НАД лентой раздела «Друзья» — тоже удалён: VK web section=friends =
  ЧИСТАЯ лента постов друзей (§1.2), рекомендациям друзей там нет места.
  «Рекомендации» остаются в FeedFilterBar-dropdown (заголовочный таб VK web
  «Все новости / Рекомендации»), в меню-навигации их нет — как в VK web.
- **Fix #354 #NOTIF-FILTER-ACTION**: тип redesign-уведомления = (1) имя из
  dots_menu (open_setting/unsubscribe) → substring-маппинг на категории;
  (2) фолбэк — глагол действия из `text`; (3) фолбэк — прежний маппинг
  entity.type (фото/видео/клип/… контент без action-глагола остаётся честным).
  VkNotificationsNotifier (channelForType/titleForType/pluralTitle/
  buildActionVerb/canReplyToType) — принять точные generic-типы
  ("like"/"comment"/"reply_comment" — уже есть/"mention"* — уже есть).
  NotificationsScreen-фильтры/иконки уже матчат новые типы (не трогаю).
