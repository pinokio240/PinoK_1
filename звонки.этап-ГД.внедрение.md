## 2. Честные отклонения (no-stub, не заглушки)
- **Чат звонка**: история ленты — только если пришла в ответе `getConversationByCall`
  (члена фасада `messages.getHistory` нет); отправка/вложения/эмодзи не рендерятся
  (нет `messages.send`); «Перейти в мессенджер» не рендерится (навигация в `:app` недоступна).
- **FCPanel**: кнопка `FCPanel__add` не рендерится (нет `messages.getConversations` в фасаде);
  persist плиток (localStorage `fc-heads`) недоступен — SovaPrefs запретный файл этапа;
  плитка без peer не создаётся; recordId=0 — крестик честно disabled.
- **Модалка расписания**: контролы реверса ModalScheduleCall (18 полей) без API-мутатора
  в фасаде не рендерятся — рендерятся имя и дата/время.

## 3. Верификация (статическая, песочница без SDK)
- Скобочный баланс (string-aware сканер: строки/комментарии/тройные литералы/`${}`): 11/11 файлов depth=0, min≥0.
- #NULL-EXPLICIT: 0 `!!`/`?.`/`?:` в добавленных строках и новых файлах. Агент Г оставил
  13 нарушений — исправлены оркестратором (захват val, if-цепочки; места: parseCallTarget,
  join-блок CallScreen, videoArgs SovaNavHost). Остаточный хит — унаследованный литерал
  `incomingPayload?.length ?: 0` в модифицированной строке легаси-лога CALL START (не тронут).
- Сигнатуры фасада сверены построчно с `CallsDependencies.kt` (editCall/deleteScheduledCall/
  forceCallFinish/getAnonymTokenByLink/joinConversationByLink/searchForCallTargets/getConversationByCall/removeFromHistory).
- 0 коллизий имён новых top-level деклараций; все новые импорты — с прецедентами в проекте.
- Запретные файлы (CallsDependencies/VKApiClient/CallsSectionRepository*/SovaPrefs/SettingsScreen)
  — 0 строк в диффе; скоупы Г/Д не пересеклись.

## 4. Что открывает
- Шапка раздела = веб-паритет: планирование, join по ссылке (включая анонимный вход), создание
  с поиском и видео; Scheduled-секция управляема (start/edit/delete).
- Redial-видео и видеозвонок из поиска работают end-to-end.
- Главная раздела получила панель быстрых звонковых чатов; чат звонка доступен из плитки.

## 5. Чек-лист пользовательской проверки (штамп calls-2026.09.06-1)
1. Звонки → «Создать звонок»: ввести имя — список поиска, выбрать — Аудио/Видео кнопки.
2. Видеозвонок другу из Истории (redial) — камера должна включиться на вызываемой стороне
   (до волны-4 video терялся — проверять именно видео).
3. «Запланировать»: имя + дата/время → звонок появляется в табе «Запланированные»;
   «Редактировать»/«Начать сейчас»/«Удалить» — работают, список обновляется.
4. «Присоединиться по ссылке»: вставить ссылку vk.ru/call/join/… (опц. пароль ?p=) → вход в звонок;
   без профиля — запрос имени (анонимно).
5. «Главная» → плитки «Быстрые звонковые чаты»: тап открывает чат звонка (шапка/лента/кнопка
   «Звонок»), крестик убирает чат из списка (история обновляется).
6. Регресс: обычные аудио/видео звонки (исходящий/входящий), история/пропущенные/записи/
   расшифровки/настройки — без изменений (волна-3 в силе).
