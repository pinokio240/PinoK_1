## §1. Cookies (28 шт., все имена, значения скрыты)

Стандартная `remix*`-семья VK web: `remixsid` (автосессия — СЕКРЕТ), `httoken`, `remixlang`,
`remixdt/ff/gp/ua/uas/uacck/sf/suc/stid/stlid/nsid/dmgr/seenads`, экранные (`remixscreen_*` —
width/height/dpr/depth/orient/winzoom: `2560/1440/1/…/2560`), цветовые
(`remixcolor_scheme_mode`, `remixdark_color_scheme`), `_clientId`, `remixnsid`.
Чужой домен: `is_gdpr(_b)` на `.yandex.net` (трекер).
Для PinoK: ничего нового — cookie-модель web не переносится (у нас OAuth-токены), но
`remixscreen_*`-подход «приборка» подтверждает детект устройства web-клиентом.

### 3.2 Канальный диалог (`vkme_channel_*`, `ChannelMain`)

- Шапка канала: название, «40,6K подписчиков», «Загружается...» (плейсхолдер подгрузки), `unsubscribe`.
- Лента: `vkme_channel_posts_scroll` → `vkme_channel_posts_history` → `vkme_channel_posts_list`
  → 10× `vkme_channel_post`; разделители дат «вчера/сегодня»; `vkme_channel_unread_separator`
  («Есть непрочитанные сообщения»); `vkme_channel_history_loader_upper` (пагинация вверх).
- Пост канала: текст; вложения (10 постов: фото-галереи ×1–3, видео с длительностями `0:13`,
  клип `Клип @<screen_name>`, YouTube-источник текстом); счётчики просмотров/реакций
  (`1,3K`), время «08:59», «1 комментарий»; ссылки-цитаты `vk.ru/wall-…`; внутренние
  `reaction chip` на каждом посте; `PhotoItem__blur` с **base64 thumbhash-плейсхолдером**
  (`--thumbhashUrl: url(data:image/png;base64,…)`) — превью до загрузки.
- Реакции-чипы: `vkme_message_reaction_chip_{1,2,3,4,5,7,10,16,27,30,31}` — 10 уникальных
  на странице; имена из aria: Большой палец вверх, Сердце, Смеюсь до слёз, Огонь, Ругаюсь,
  Окей, Плачу, Грущу, Неординарно, Хлопушка, В шоке.
- Футер диалога: `vkme_channel_footer_enable_notifications` — «включить уведомления»
  (канал читается без подписки → мягкий апселл уведомлений), «Поиск по каналу» (aria),
  «Убрать чат из списка».
- Справа `channels_list_recommended`: «Рекомендации» + карточки других каналов
  (название + анонсный текст поста).

Видео/Игры/Сервисы/Закладки 16/Файлы/Помощь), блок «Уведомления 20», мини-плеер с треком

трек в плеере этой страницы **совпадает** с `audio_v21_track` из §2.2 — кросс-подтверждение
модели аудио-персистентности (один и тот же глобальный плеер на всех страницах).
