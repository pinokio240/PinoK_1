## 5. Технические спецификации (для реализации)

### 5.1 Fields-блок админа для `groups.getById`
`is_admin,admin_level,is_advertiser,can_message,can_suggest,can_post,member_status`
- Веб-эталон (сверка §3.1): ответ `is_admin:1, admin_level:3, is_advertiser:1, can_post:1, can_message:1`.
- Web-enum (справочно, НЕ части VK API): `USER:0, MODERATOR:1, EDITOR:2, ADMINISTRATOR:3, HOST:4, EVENT_CREATOR:5, CREATOR:6, PSEUDO_ADVERTISER:100`. В VK API `admin_level` = 0..3 (1 модератор/2 редактор/3 администратор) — UI-градации только 1/2/3.

### 5.2 `groups.edit` — параметры (официальные)
`group_id` (обяз.), далее секциями: `title`, `description`, `screen_name`, `website`, `public_category`, `wall` (0/1/2/3), `photos`, `video`, `audio`, `docs`, `topics`, `stories`, `messages` (0/1/2), `enable_messages`, `enable_photo_comments`, `subject`, `action_button` (JSON), `main_section`, `secondary_section` и др. Ответ `{"response":1}`.

### 5.3 `groups.editManager`
`group_id`, `user_id`, `role` (moderator/editor/administrator), `contact_phone`, `contact_email`, `contact_position`; снятие = `remove=1` (без role). Ограничение: менять роли может только owner/administrator.

### 5.4 `stats.get`
`group_id` (может `-N`), `interval` (day/week/month), `interval_count`, `filters=visitors,views,reach,activity`, `timestamp_from/to`. Ответ `response[].{period, visitors:{views,visitors,…}, reach:{reach,reach_subscribers}, activity:{likes,replies,subscribes…}}`.
### 5.5 `stats.getPostReach`
`owner_id` (`-groupId`), `post_ids` (до 100 `postId`). Ответ: `reach, reach_subscribers, reach_users, likes, link_clicks, …`.

### 5.6 Баны/заявки
- `groups.getBanned`: `group_id`, `count/offset`, `fields` → `profiles[]` + `banned_info[]` (`end_date`, `reason`).
- `groups.banUser`: `group_id`, `owner_id`, `reason` (0-4), `end_date` (0 = навсегда), `comment`.
- `groups.unbanUser`: `group_id`, `owner_id`.
- `groups.getRequests`: `group_id`, `count/offset` → `profiles[]`.
- `groups.approveRequest`: `group_id`, `user_id`.

## 12. Разбор HAR-дампа веб-сессии админки (vk.ru.har, tempfile.org/ZqCpwh7wcEX, 2026-09-25)

### 12.1 Полная карта секций настроек (левое меню /pluton240/settings/*)

### 12.2 Эндпоинты и форматы
- `al_profile.php` POST (al=1, __query={screen_name}), act=edit|activity|addresses|blacklist|search(from=blacklist)|chats|apps|tokens|event_log → `{"payload":[0,[false,"<HTML секции>"]]}`. act=edit содержит форму «Информация»: public_category, public_subtype, group_subject, group_category_0/1, event_host, sel_groups_edit_city/school.
- `groupsedit.php` POST: act=save_comments (gid, enable_replies, obscene_filter, hash) — фильтр мата и ответы комментов; act=save_addresses_section (id, enabled, main_section, hash); act=search_add_box (gid, to=blacklist, q, offset, part, boxhash) — поиск ЛЮБОГО юзера по имени для бана (не только из списка участников!).
- `al_groups.php` POST act=get_onboarding_modal|get_geo_ban|get_top_warnings|get_moderation_podcast_info|get_glavred_info|get_fast_groups_links|get_moderation_actions (al_id, group_id) — мелкие инфо-загрузчики (в этой сессии почти пустые, приоритет низкий).
- ЖУРНАЛ ДЕЙСТВИЙ: POST `https://vk.ru/{screen_name}?act=event_log` body `al=1&filter=1&next_from={ts}` → HTML, где `data-additional="[[hash,[{action_type,ts,admin_id,id}]]]"` (HTML-unescape → JSON). Пагинация — next_from = ts последнего элемента (в сессии 170 запросов = бесконечный скролл). Mobile API аналога НЕ имеет → единственный путь: web-запрос с remixsid (cookie), как AlAudioFallback.
- Хэши форм: каждый act отдаёт свои hash/boxhash (18–20 hex) — web-fallback должен парсить их из HTML перед save-запросом.
