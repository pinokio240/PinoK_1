## Ключевой вывод
Снапшот фиксирует **`wall.repost`** (Поделиться / Отправить запись в сообщество), а не создание нового поста (`wall.post`). Медиа НЕ загружается (репост использует готовые фото исходного поста). Ни одного `wall.post`/`photos.*`/upload-вызова в HAR нет.

## Главный метод: `wall.repost`
- **URL:** `POST https://web.api.vk.ru/method/wall.repost?v=5.289&client_id=6287487`, `Content-Type: application/x-www-form-urlencoded`.
- **Параметры:**
  - `object=wall{owner_id}_{post_id}` — исходный пост, которым делимся (owner_id отрицательный для группы).
  - `message=` — текст поверх репоста.
  - `group_id={target_group}` — куда отправляем (положительный id сообщества-приёмника).
  - `friends_only=0`, `close_comments=0`, `mute_notifications=0`, `mark_as_ads=0`, `publish_date=` (отложка), `ref=group`, `entry_point=share`, `track_code=`.
  - `access_token=vk1.a…` — токен в теле формы.
- **Ответ (HTTP 200):**
```json
{"response":{"success":1,"post_id":3876,"reposts_count":3,"likes_count":11,
  "reactions":{"count":11,"items":[{"id":0,"count":11}]},
  "badges":{"type":11,"id":4883,"owner_id":-157611757}}}
```
- После успеха лента НЕ перезагружается (новый пост вставляется оптимистично из ответа).

## Подготовительные запросы (перед публикацией)
1. **`batch.call`** — данные для окна «Поделиться»:
   - `wall.getById" : {"posts":"-{owner}_{post}","extended":1}` — исходный пост для предпросмотра.
   - `groups.getById" : {"group_ids":"...","fields":"is_closed,reposts_disabled"}` — стоп-флаги (запрет репоста).
2. **`groups.get`** c `filter=editor&count=100&extended=1&fields=name,members_count` — список сообществ, куда юзер может постить (только где редактор/админ). Ответ содержит `is_admin:1, admin_level:3`.
3. `utils.getReleaseVersionsInfo` — feature-флаги (некритично).

## Паттерны прав («предложить» / «опубликовать» / «от имени группы»)
- **Право писать на стену** определяет UI: `can_post` (постить сразу), `can_suggest` (предложить), `admin_level>=3` (от имени группы).
- Репост в сообщество где юзер админ — `wall.repost` (этот снапшот).
- **`wall.post`** (создание поста на стене группы) — reference:
  - `owner_id=-{group_id}` (минус = группа), `message`, `attachments` (`photo{owner}_{pid}_{key},video…`, через запятую), `from_group=1`, `signed=0/1`, `friends_only`, `close_comments`, `publish_date`, `suggest=0`, `mark_as_ads`.
  - Ответ: `{"response":{"post_id":N,"owner_id":-G}}`.
  - **Если юзер не админ, но разрешены предложения** → тот же `wall.post` с `suggest=1` («Предложить новость»); при запрете — `error_code 214 "Access to posting denied"`.
- Загрузка медиа перед новым постом: `photos.getWallUploadServer` → upload → `photos.saveWallPhoto` → `photo{owner}_{id}_{key}` → в `attachments` wall.post. (В снапшоте нет — репост использует готовые фото.)

## UI-паттерн (из HTML)
- Ввод: `data-testid="content-editable-input"`, `aria-label="Написать комментарий…"`.
- Прикрепление: `data-testid="show-attach-dropdown"` + `<input type=file multiple accept="image/*,video/*…">`.
- Отправка: локали `box_send: "Отправить"`.
- Если `can_post=0 && can_suggest=0` — VK показывает только поле комментария (не форму создания поста).

## Ошибки (локали веба)
- `wall_edit_error` «Нельзя редактировать»
- `wall_posting_attachment_limit_exceeded_text` «Не удалось добавить файл» (лимит вложений)
- `wall_posting_network_general_error_text` «Что-то с интернетом»
- API-ошибки — стандартный `{"error":{"error_code":N,"error_msg":"…"}}`.

## Чек-лист для приложения PinoK
Сценарий «Поделиться записью в сообщество»:
1. `groups.get` c `filter=editor` — список доступных групп для UI-выбора.
2. (Опц.) `batch.call` предзагрузка исходного поста + стоп-флаги группы.
3. `wall.repost` c `object / message / group_id / флаги / entry_point=share`.
4. Обработать `{"response":{"success":1,"post_id":…}}`.

Сценарий «Создать пост на стене сообщества»:
1. Права через `groups.getById`: `can_post`, `can_suggest`, `admin_level`.
2. Загрузка фото: `photos.getWallUploadServer` → upload → `photos.saveWallPhoto`.
3. `wall.post` (owner_id=-group, message, attachments, from_group/signed/suggest по правам).
4. Ошибка 214 = нет прав; флаг `suggest=1` = «Предложить».
