## Дубли и консолидация
Повторные строки метода — **обёртки с разной семантикой**, консолидация не требуется:
- `messages.send` ×9 — прямое отправление / ответ (reply) / пересылка (forward) / сервисные отправители (уведомители, каналы, звонки).
- `video.get` ×4 — по id / свои / с мета комментариев (extended) / для группового контура.
- `catalog.getAudioSearch` ×4, `catalog.getSection` ×3 — разные блоки каталога.
- `users.get` ×3, `groups.getById` ×3, `likes.add` ×3, `wall.post` ×3 — разные поля/сценарии.
- Осознанные надстройки (не дубли): `audioAddReliable` = `audio.add` + web-fallback (AlAudioFallback) при API-отказе — паттерн #AUDIO-TOGGLE-OWNING.
