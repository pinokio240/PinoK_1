# Админ-панель сообщества: разбор HAR и план реинжиниринга

> Источник: `vk.ru_11.har` (72 МБ), `vk.ru.har` (26 МБ), `vk.ru_чат.har` / `vk.ru_чат_2.har`.
> Сообщество Pluton tut (`pluton240`, gid `165284550`, `-165284550`), админ `171093180`.
> Снято 24–25.09.2026 в веб-клиенте `vk.ru` (BFF web2, release ~247900).
> Транспорты: `web.api.vk.ru/method/*?v=5.289&client_id=6287487`, `api.vk.ru/method/*`, legacy `vk.ru/*.php`.

---

## 1. Транспорты и авторизация

| Транспорт | Формат | Особенности |
|---|---|---|
| `web.api.vk.ru/method/<m>` | POST urlencoded | `Origin: https://vk.ru`, `Referer: https://vk.ru/`, `access_token` последним полем тела. v=5.289, client_id=6287487 |
| `api.vk.ru/method/<m>` | POST urlencoded | Тот же формат; живут `owners.*`, `donut.*` |
| `batch.call` | POST **JSON** | `{"requests":[{"id":"0","method":"...","params":{...}}]}` → `{"responses":[{"id":"0","body":{"response":…}}]}`. До 15+ методов за запрос |
| `vk.ru/*.php` (legacy) | POST urlencoded | `X-Requested-With: XMLHttpRequest`, обязательны `al=1&al_id=<uid>`, **`hash=<hex>`** (CSRF из состояния страницы). Ответ — обёртка `{"payload":[0,[…]],"static":…,"statsMeta":{…}}` |

**hash для legacy** берётся из `groups.getLegacyModalsHashes` (batch) → `more_info_hash, delete_cover_hash, admin_tips_address_hash, admin_tips_hide_hash`, либо из разметки страницы.

## 6. Что доснять в следующей сессии CDP

1. Подписчики: удалить участника + сменить роль (WRITE `groups.removeUser`/`groups.editManager`).
2. Статистика: полная цепочка `statsDashboard` (layout → data для каждой карточки).
3. Архив историй: открыть историю → статистика → зрители (`stories.getById/getStats/getViewers/getArchive`).
4. Комментарии: помимо save_comments — действие над комментарием (удалить/ответить/бан).
5. События: открыть раздел, проверить, чем грузится (если API нет — зафиксировать).
6. Канал и Боты: сохранить настройки.
7. Меню: переименовать пункт/сменить URL (полный WRITE).
8. `batch.call` — зафиксировать 2-3 полных цикла (запрос+ответ) для реализации транспорта.
