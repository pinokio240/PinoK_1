## §1. Этап Б — История и Пропущенные (план §4-Б)

| Пункт | Что сделано | API |
|---|---|---|
| Б1 | Пагинация scroll-to-end: LazyColumn-хвост → `loadMore` (страницы по 25, append без дублей по callId, `loadMoreInFlight`-dedupe, футер-спиннер, `hasMore`) | `callsGetHistory(count, offset, filter, paginationMarker)` |
| Б2 | Redial: кластерные кнопки «Аудиозвонок X» / «Видеозвонок X» | `CallStarter.startCall(peerId, video)` |
| Б3 | Меню «Действия» строки: «Убрать из списка» (с подтверждением), «Очистить историю» (ConfirmClearHistoryDialog); групповые аналоги; после успеха — авто-refresh HISTORY+MISSED | `callsDeleteHistoryRecords` / `callsClearHistory` / `callsDeleteGroupHistoryRecords` / `callsClearGroupHistory` |
| Б4 | Кластеры «Имя (N)» / «Групповой звонок dd.MM.yyyy» (`clusterHistoryEntries`: соседние записи одного peer сливаются, групповые — нет); бейдж пропущенных в сайдбаре (`missedCount` → BadgedBox «99+», стиль unread-badge SovaNavHost) | данные `callsGetHistory{filter:"missed"}` |

Репозиторий (`CallsSectionRepository` + Impl): `loadMore(key)`, `removeFromHistory(recordIds, groupId)`, `clearCallHistory(groupId)`, `missedCount: StateFlow<Int>`; `CallsSectionState` + `loadingMore`/`hasMore`; `CallHistoryEntry` + `recordId`/`groupId` (дефолты — обратная совместимость).

**Известные ограничения (зафиксированы честно):**
1. **Пагинация через offset**: `VKApiClient` возвращает только `response.items` и отбрасывает `pagination_marker` — маркерная пагинация недоступна через фасад; offset работает (первая страница 0, конец = страница < 25). Переход на маркер = 1 строка в VKApiClient (этап И/фоллоу-ап).
2. **Video-флаг обрывается**: `startCall(peerId, video=true)` доходит до `SovaApp.pendingOutgoingCallVideo=true`, но дальше SovaNavHost строит маршрут без video, а CallScreen жёстко шлёт `video=false`. Файлы вне скоупа волны-3 — **фикс в этапе Г**.
3. **«Убрать чат из списка»** = крестик FCPanel-плитки (REV-UI §1.5): FCPanel в PinoK строится на Этапе Д; API (`deleteHistoryRecords`) уже реально покрыт пунктом «Убрать из списка».
4. У «Пропущенных» нет пункта «Ещё» (по срезу REV-UI §3.2).

## §3. Этап З — Настройки звонков (план §4-З)

Секция уже существовала как вкладка `settings_calls` в `SettingsScreen` — добавлены 3 подсекции (существующие не тронуты, SovaNavHost не потребовался):

1. **Серверные настройки**: `callsGetSettings()` → РЕАЛЬНЫЙ список `toggles[{name,enabled}]` (словарь 11 подписей из ui-срезов §9.3, fallback на name) + privacy-блок «Определение IP» (`calls_ip`/`ip_setting_enabled`, read-only — write-API серверных флагов нет, §5.р5).
2. **Персональные**: `callsGetUserSettings()` → нормализация `response.settings|response`; boolean-поля — переключатели (оптимистично, откат + Toast с реальной ошибкой через `lastApiError`), числа/строки — read-only; запись `callsSetUserSettings(payload)`, payload = `body.deepCopy()` + изменённое поле — тот же набор, что прочитали.
3. **Устройства и шумодав по умолчанию** (SovaPrefs): `calls_mic_default` (реальный `AudioManager.getDevices(INPUT)`, значение `type:address`), `calls_route_default` (auto/speaker/earpiece/bt), `calls_camera_default` (front/back с проверкой `LENS_FACING`), `calls_noise_cancel_default` (AUTO/SIMPLE/NEURAL, default NEURAL по localStorage-дампу). Потребитель — Ж4.

## §6. Чек-лист пользовательской проверки (сборка со штампом calls-2026.09.05-14)

1. История: скролл вниз → дозагрузка (футер-спиннер, без дублей).
2. Кластеры: соседние звонки одного человека слились «Имя (N)»; групповые отдельны.
3. Redial аудио/видео: кнопки стартуют звонок (в логе CALL START штамп -14; видео пока порежется старой цепочкой — ожидаемо).
4. «Действия» → «Убрать из списка» — строка исчезает; «Очистить историю» с подтверждением — список пустеет.
5. Сайдбар: бейдж на «Пропущенные».
6. Записи: карточки; тап → плеер играет (аудио точно; видео — по типу URL); скачать/копировать/удалить; мультивыбор.
7. Расшифровки: список/просмотр/правка/удаление; пустое состояние.
8. Настройки → Звонки: серверные тумблеры (реальный ответ), персональные переключатели (откат при ошибке), дефолты устройств сохраняются.
